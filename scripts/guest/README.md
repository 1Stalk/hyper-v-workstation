# Гостевые скрипты виртуальных машин (Guest In-VM Scripts)

В этой папке хранятся скрипты, которые внедряются внутрь гостевой операционной системы Windows 11 (`C:\Setup\` внутри VHDX) при сборке и клонировании:

1. **`ensure_static_ip.ps1`**:
   - Автоматический сторожевой сервис (Watchdog), работающий по расписанию в планировщике задач Windows (`SYSTEM`).
   - Контролирует сетевые интерфейсы: назначает статический IP в сети `VM-Gaming-Switch` (192.168.100.x), переключает шлюз и DNS при работе в режиме Proxy / Direct, предотвращает сбои адресации и задержки RDP/Moonlight.
   - Снимает ограничение пустых паролей Windows (`LimitBlankPasswordUse = 0`), обеспечивая мгновенный вход и PowerShell Direct.

2. **`Guest-HyperV-CleanID.ps1`**:
   - Автономный инструмент сброса идентификаторов внутри гостевой ОС.
   - Рандомизирует `MachineGuid`, `HardwareProfileGuid`, `ProductId`, `BuildGuid`, `InstallDate`, телеметрию `SQMClient\MachineId`, серийный номер тома `C:` (VolumeID) и имя компьютера.

3. **`Verify-HWID.ps1`**:
   - Утилита глубокого аудита оборудования гостевой системы.
   - Выводит все аппаратные идентификаторы (SMBIOS BIOS, серийный номер платы, UUID, серийники дисков, MAC-адреса, GUID реестра), позволяя убедиться в уникальности виртуальной машины.
