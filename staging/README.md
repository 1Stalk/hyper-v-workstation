# Папка временных пакетов и драйверов (Staging)

Эта папка используется скриптами развертывания для временного хранения и подготовки драйверов, виртуального дисплея (VDD) и серверных компонентов Sunshine перед внедрением в образ диска VHDX.

## Необходимые компоненты:
Для работы развертывания в этой папке требуются:
- `sunshine.msi` — установщик стримингового сервера Sunshine
- `VirtualDisplayDriver-x64.zip` (распакованный в `VDD\VirtualDisplayDriver\`) — виртуальный дисплей для GPU-PV
- `nefcon.zip` (распакованный в `nefcon\`) — консольная утилита установки драйверов Nefarius
- `Volumeid64.exe` — утилита Sysinternals для рандомизации серийного номера тома C:

## Автоматическая загрузка:
Все необходимые файлы можно загрузить одной командой:
```powershell
powershell -ExecutionPolicy Bypass -File scripts\00-Download-Tools.ps1
```

*Примечание: бинарные файлы и извлеченные драйверы хоста исключены из git через `.gitignore`.*
