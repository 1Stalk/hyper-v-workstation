## 2. Расчет выделения 1 ГБ видеопамяти (VRAM) в GPU-PV

В подсистеме Hyper-V GPU Partitioning шкала ресурсов нормализована до **1 000 000 000** условных единиц (100% ресурсов физической карты):
- Общая физическая память GTX 1050 Ti = **4096 МБ** = `1 000 000 000`.
- Необходимый объем памяти для гостевой VM = **1024 МБ (1 ГБ)**.
- Доля VRAM для виртуальной машины:
  $$\frac{1024\text{ МБ}}{4096\text{ МБ}} = 25\% = 0.25 \times 1\,000\,000\,000 = \mathbf{250\,000\,000}$$

### Параметры PowerShell для ограничения до 1 ГБ VRAM:
```powershell
Set-VMGpuPartitionAdapter -VMName $VMName `
    -MinPartitionVRAM 1 `
    -MaxPartitionVRAM 250000000 `
    -OptimalPartitionVRAM 250000000 `
    -MinPartitionCompute 1 `
    -MaxPartitionCompute 250000000 `
    -OptimalPartitionCompute 250000000 `
    -MinPartitionDecode 1 `
    -MaxPartitionDecode 250000000 `
    -OptimalPartitionDecode 250000000 `
    -MinPartitionEncode 1 `
    -MaxPartitionEncode 18446744073709551615 `
    -OptimalPartitionEncode 18446744073709551615
```

### Масштабирование на 4-5 виртуальных машин в будущем:
- **4 виртуальные машины**: каждая получает ровно $250\,000\,000$ (1 ГБ). Суммарно $4 \times 1\text{ ГБ} = 4\text{ ГБ}$ (100% физической видеопамяти карты).
- **5 виртуальных машин**: каждая получает по $200\,000\,000$ (~800 МБ) или динамический оверкоммит с `MinPartitionVRAM 1` и `MaxPartitionVRAM 250000000`.

## 3. Решение задачи отображения: Опыт "VMware Workstation" для игровой VM

### Почему штатные средства Hyper-V (`vmconnect.exe`) не подходят для игр:
1. **Базовый сеанс (Basic Session)**: использует синтетический видеоадаптер Hyper-V Video Device. Ограничен 30 кадрами в секунду, рендерит игры через программный растеризатор CPU, не передает звук.
2. **Расширенный сеанс (Enhanced Session / RDP)**: перенаправляет графику через протокол RDP. Мышь в 3D-играх срывается (камера бешено вращается в потолок/пол), задержка ввода (latency) превышает 50–100 мс, частота кадров проседает.
3. Виртуальный графический адаптер GPU-PV не имеет физического видеовыхода (HDMI/DisplayPort).

### Архитектура решения:
```
+-----------------------------------------------------------------------------------+
| ХОСТ (Windows 11 Enterprise)                                                      |
|                                                                                   |
|  +--------------------------------+       +------------------------------------+  |
|  | Moonlight Client (Оконный режим) | <----+ | Hyper-V Workstation Launcher (GUI) |  |
|  | - Отдельное окно, как в VMware |       | - Боковая панель со списком всех VM|  |
|  | - 60 FPS / Direct3D 11/12     |       | - Кнопки [Старт], [Стоп], [Консоль]|  |
|  | - Захват "сырой" мыши (Raw)   |       | - Клонирование VM в 1 клик         |  |
|  | - Задержка < 2 мс (по NAT)    |       +------------------------------------+  |
|  +----------------+---------------+                                               |
+-------------------|---------------------------------------------------------------+
                    | Внутренний виртуальный коммутатор (192.168.100.0/24)
+-------------------|---------------------------------------------------------------+
| ГОСТЕВАЯ VM (Windows 11 Pro 25H2) |                                               |
|                   v                                                               |
|  +--------------------------------+                                               |
|  | Сервер Sunshine                |                                               |
|  | (Захватывает кадры с VDD через |                                               |
|  |  NVFBC/DXGI и жмет через NVENC)|                                               |
|  +----------------+---------------+                                               |
|                   ^                                                               |
|  +----------------+------------------------------------------------------------+  |
|  | Virtual Display Driver (VDD) - Виртуальный монитор 1080p@60Hz               |  |
|  | Партиционированный GPU: NVIDIA GeForce GTX 1050 Ti (Выделено 1 ГБ VRAM)    |  |
|  +-----------------------------------------------------------------------------+  |
+-----------------------------------------------------------------------------------+
```

1. **Virtual Display Driver (VDD)** внутри гостевой ОС создает постоянный виртуальный Full HD монитор, напрямую привязанный к GTX 1050 Ti.
2. **Sunshine Service** в гостевой ОС перехватывает готовые кадры видеокарты с нулевым копированием и сжимает их с помощью аппаратного чипа NVENC.
3. **Moonlight Client** запускается на хосте в **оконном режиме**:
   ```cmd
   Moonlight.exe --display windowed stream 192.168.100.11 Desktop
   ```
   Это дает полностью привычное окно (с заголовком, кнопками свернуть/развернуть/закрыть, свободным перетаскиванием), захватом курсора мыши и поддержкой геймпадов.
4. **Консоль управления "Hyper-V Workstation"**: Нативный легковесный GUI на PowerShell WPF, который отображает список всех виртуальных машин, статус их ресурсов и открывает их консоли в один клик.

## 4. План реализации по шагам

### Этап 1: Сетевая инфраструктура хоста
Создание постоянного внутреннего коммутатора и службы NAT:
- Имя свитча: `VM-Gaming-Switch`
- IP шлюза хоста: `192.168.100.1/24`
- Подсеть NAT: `192.168.100.0/24`
- Статический IP для VM 1: `192.168.100.11` (для последующих: `192.168.100.12`, `192.168.100.13` и т.д.).

### Этап 2: Подготовка и извлечение драйверов видеокарты
Скрипт автоматически копирует файлы драйвера хоста:
- Каталог `C:\Windows\System32\DriverStore\FileRepository\nv_dispig.inf_amd64_0afec3f2050014a0`
- Системные библиотеки `C:\Windows\System32\nv*.*`
- Подготавливает их в промежуточной папке для автономного внедрения.

### Этап 3: Быстрое развертывание гостевой ОС через DISM
Вместо долгой ручной установки через установщик Windows с обходом проверок TPM/CPU:
1. Создается динамический диск `Gaming-VM1.vhdx` (60 ГБ).
2. Диск размечается в GPT (системный раздел EFI 100 МБ, основной раздел NTFS).
3. Командой `dism /Apply-Image` образ Windows 11 Pro (Индекс 3 из ISO) разворачивается на диск за 2-3 минуты.
4. Создаются загрузочные записи UEFI командой `bcdboot`.
5. Внедряется файл автоответов `unattend.xml` (создание пользователя `Gamer`, автовход, включение RDP, схема "Высокая производительность").
6. Драйверы NVIDIA копируются напрямую в `Windows\System32\HostDriverStore\FileRepository` и `Windows\System32`.
7. Размещаются установщики Virtual Display Driver и Sunshine.

### Этап 4: Создание виртуальной машины и подключение GPU-PV
```powershell
New-VM -Name "Gaming-VM1" -Generation 2 -MemoryStartupBytes 8GB -VHDPath "C:\Hyper-V\VMs\Gaming-VM1.vhdx" -SwitchName "VM-Gaming-Switch"
Set-VMProcessor -VMName "Gaming-VM1" -Count 4
Set-VMFirmware -VMName "Gaming-VM1" -EnableSecureBoot Off
Set-VM -VMName "Gaming-VM1" -GuestControlledCacheTypes $true -LowMemoryMappedIoSpace 1GB -HighMemoryMappedIoSpace 32GB -AutomaticStopAction TurnOff

Add-VMGpuPartitionAdapter -VMName "Gaming-VM1"
Set-VMGpuPartitionAdapter -VMName "Gaming-VM1" -MinPartitionVRAM 1 -MaxPartitionVRAM 250000000 -OptimalPartitionVRAM 250000000 -MinPartitionCompute 1 -MaxPartitionCompute 250000000 -OptimalPartitionCompute 250000000 -MinPartitionDecode 1 -MaxPartitionDecode 250000000 -OptimalPartitionDecode 250000000 -MinPartitionEncode 1 -MaxPartitionEncode 18446744073709551615 -OptimalPartitionEncode 18446744073709551615
```

### Этап 5: Настройка видеопотока и первого запуска
1. Запуск виртуальной машины.
2. Проверка распознавания `NVIDIA GeForce GTX 1050 Ti` в Диспетчере устройств.
3. Активация виртуального дисплея (VDD) 1080p 60Hz.
4. Конфигурация службы Sunshine с автозапуском при старте системы.
5. Установка клиента Moonlight на хосте и связывание (Pairing) с сервером Sunshine.

### Этап 6: Создание консоли "Hyper-V Workstation" и масштабирование
1. Создание скрипта-лаунчера `HyperV-Workstation.ps1` (WPF GUI).
2. Подготовка скрипта `Clone-GamingVM.ps1`:
   - Базовый VHDX первой настроенной машины переводится в режим "Master Image" (Read-Only).
   - Для новых машин создаются разностные диски (Differencing VHDX):
     ```powershell
     New-VHD -ParentPath "C:\Hyper-V\VMs\Gaming-Base.vhdx" -Path "C:\Hyper-V\VMs\Gaming-VM2.vhdx" -Differencing
     ```
   - Запуск новой машины VM2, VM3, VM4, VM5 занимает **менее 30 секунд** и экономит дисковое пространство.
   - Каждой новой машине автоматически выделяется 1 ГБ VRAM и создается персональная кнопка запуска в панели.

## 5. План проверки и валидации

1. **Проверка адаптера на хосте**:
   `Get-VMGpuPartitionAdapter -VMName "Gaming-VM1"` подтверждает лимит `250000000`.
2. **Проверка в гостевой ОС**:
   - Диспетчер устройств: `NVIDIA GeForce GTX 1050 Ti` в статусе "Устройство работает нормально" (отсутствует Code 43).
   - Утилита `dxdiag`: вкладка "Экран" подтверждает доступность Direct3D и объем видеопамяти `1024 MB`.
3. **Тест частоты кадров и управления**:
   - Запуск оконного сеанса Moonlight на рабочем столе хоста.
   - Проверка плавности 60 FPS и корректного захвата мыши в игровом приложении.
4. **Тест одновременного запуска**:
   - Клонирование и запуск `Gaming-VM2`.
   - Проверка параллельной работы двух окон Moonlight на хосте.
