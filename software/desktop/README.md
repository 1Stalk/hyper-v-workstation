# Папка для программ гостевых виртуальных машин (Guest Desktop Software)

Поместите в эту папку файлы установщиков программ, которые должны автоматически появиться на рабочем столе (`C:\Users\Public\Desktop`) всех создаваемых и клонируемых виртуальных машин.

## Поддерживаемые форматы:
- Исполняемые файлы и архивы: `.exe`, `.msi`, `.zip`, `.rar`, `.7z`, ярлыки `.lnk`.

## Рекомендуемый набор софта:
1. **Браузер**: Google Chrome, Brave, Mozilla Firefox (например, `ChromeSetup.exe`).
2. **Удаленный доступ / Подключение**:
   - `rustdesk-*-x86_64.exe` (Open-source Remote Desktop)
   - `RealVNC` / VNC Viewer
3. **Архиватор**: `WinRAR` или `7-Zip`.
4. **Оптимизация / Твикеры**: `Winhance.Installer.exe`.
5. **Игровой софт**: Лаунчеры игр, Steam, Discord, Telegram и т.д.

## Как это работает:
При развертывании базового диска (`03-Build-GamingVM.ps1`) и при создании/клонировании каждой ВМ (`04-Configure-GPU-PV.ps1`, `05-Clone-VM.ps1`), скрипты автоматически копируют все файлы из этой директории напрямую на публичный рабочий стол ВМ. Пользователю не нужно заново переносить софт в каждую виртуалку вручную.

*Примечание: тяжелые бинарные файлы (`.exe`, `.rar`, `.zip`) исключены правилами `.gitignore` и не попадут в репозиторий GitHub.*
