# Конфигурация прокси-маршрутизации (Proxy Configurations)

В этой папке хранятся профили внешних SOCKS5-прокси серверов и их привязка к виртуальным машинам.

## Файлы:
- `proxy-profiles.example.json` — эталонный шаблон структуры профилей (отслеживается в Git).
- `proxy-profiles.json` — рабочий файл настроек пользователя (создается автоматически из шаблона, игнорируется в Git для защиты паролей).
- `sing-box.json` — динамически генерируемый конфиг ядра маршрутизации Sing-box (создается автоматически, игнорируется в Git).

## Добавление прокси через интерфейс:
Вам не требуется редактировать JSON-файлы вручную:
1. Запустите консоль управления `Start-HyperV-Workstation.cmd`.
2. Выберите виртуальную машину в списке.
3. В блоке **Внешний SOCKS5 Прокси** нажмите кнопку **[➕ Добавить]** или введите строку вида:
   `server:port:username:password` (например, `198.51.100.10:1080:proxyuser:secretpassword`).
4. Нажмите **[Применить к VM]** — трафик этой конкретной виртуальной машины будет прозрачно изолирован и направлен через выбранный прокси.
