# Hyper-V GPU-PV Gaming Virtual Machine Cluster

Автоматизированная инфраструктура игровых виртуальных машин на базе технологии **Hyper-V GPU Partitioning (GPU-PV)** с оконным интерфейсом в стиле **VMware Workstation**.

---

## 1. Спецификация хостовой системы

- **Процессор**: Intel Xeon E5-2696 v3 (Haswell, 18 ядер / 36 потоков, 2.3–3.1 GHz, поддержка VT-x, VT-d, SSE4.2, POPCNT).
- **Оперативная память**: 64 ГБ DDR4 ECC.
- **Видеокарта**: NVIDIA GeForce GTX 1050 Ti (4096 МБ VRAM, драйвер 560.94 WDDM с поддержкой до 8 одновременных NVENC сессий).
- **Хостовая ОС**: Windows 11 Enterprise (25H2 Build 26200).
- **Гостевая ОС**: Windows 11 Pro (25H2, образ `install.wim` Индекс 3).

---

## 2. Архитектура решения

### Выделение ресурсов на одну виртуальную машину:
- **vCPU**: 4 виртуальных ядра (позволяет запустить до 5 VM, оставив 16 ядер хосту).
- **RAM**: 8 ГБ статической оперативной памяти.
- **VRAM**: **Ровно 1 ГБ (1024 МБ)**. Нормализованное значение GPU-PV: `250 000 000` из 1 млрд (25% от 4 ГБ).
- **Жёсткий диск**: **150 ГБ** (динамический/разностный VHDX, системный раздел C: расширен до 149.87 ГБ).

## 4. Быстрый запуск

1. Запустите консоль управления:
   - Через ярлык **`Hyper-V Workstation`** на рабочем столе, либо
   - Двойным кликом по `Start-HyperV-Workstation.cmd`.
2. Выберите виртуальную машину `Gaming-VM1` в списке слева.
3. Нажмите **[▶ Запустить VM]**.
4. Нажмите **[🖥️ Открыть стрим (Moonlight)]** — откроется отдельное окно с разрешением 1024x768 @ 60 FPS.
5. Для создания новых машин (VM2..VM5) нажмите кнопку **[➕ Клонировать новую VM]** — машина будет создана за 30 секунд с диском 150 ГБ и 1 ГБ VRAM.
